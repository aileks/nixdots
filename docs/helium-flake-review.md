# Helium flake review

Reviewed 2026-09-08 for this x86_64-linux NixOS unstable desktop and Mango/NVIDIA migration.

Inspected revisions: [schembriaiden/helium-browser-nix-flake `9d5a2477fcc86e78abef68ab1b7928a20e664c4b`](https://github.com/schembriaiden/helium-browser-nix-flake/tree/9d5a2477fcc86e78abef68ab1b7928a20e664c4b) and [oxcl/nix-flake-helium-browser `6e30efa9db0559dd987322f2503cce2f451005ae`](https://github.com/oxcl/nix-flake-helium-browser/tree/6e30efa9db0559dd987322f2503cce2f451005ae).

Recommend **oxcl with the wrapper correction below** for this machine. It preserves Helium's launcher, supplies GTK integration, and exposes a package `flags` argument. Schembriaiden additionally disables component updates and background networking, and suppresses outdated-browser warnings until 2099. Those browser behavior changes are unnecessary for this migration. [oxcl package](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/helium.nix), [schembriaiden package](https://github.com/schembriaiden/helium-browser-nix-flake/blob/9d5a2477fcc86e78abef68ab1b7928a20e664c4b/flake.nix)

Both currently repackage **official binary release 0.16.5.1**, published September 4 and based on Chromium 152.0.7977.82. Neither compiles the browser from source. Both x86_64 fetch hashes match the release's published asset digests. [Upstream release](https://github.com/imputnet/helium-linux/releases/tag/0.16.5.1)

Use `github:oxcl/nix-flake-helium-browser`, set `inputs.nixpkgs.follows = "nixpkgs"`, and retain the reviewed revision in `flake.lock`. Install its default package with `override { flags = [ "--ozone-platform=wayland" ]; }`. Its modules are unnecessary for this package replacement. Explicit Ozone selection avoids relying on automatic backend selection. [Package interface](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/helium.nix), [Chromium Ozone documentation](https://chromium.googlesource.com/chromium/src/+/main/docs/ozone_overview.md)

- Required local correction, implemented in `home.nix`: remove the conditional Ozone-hint `--add-flags` line from `preFixup` using a narrow `overrideAttrs`, retaining the explicit Wayland flag. This nixpkgs generates a binary wrapper that passes the shell expression literally as another URL argument. The first headless `chrome://sandbox` check failed with a multiple-target error; inspecting the generated wrapper confirmed the literal argument. The corrected package launches successfully. [Affected upstream line](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/helium.nix#L259)
- Neither package adds sandbox-disabling flags or installs a privileged sandbox helper. The inspected upstream launcher also leaves sandbox defaults intact. With the corrected package and a fresh temporary profile, headless `chrome://sandbox` reported a namespace sandbox, PID/network namespaces, and seccomp-BPF with TSYNC enabled. No sandbox-disabling flags were used. [Upstream launcher](https://github.com/imputnet/helium-linux/blob/0.16.5.1/package/helium-wrapper.sh), [Chromium Linux sandbox](https://chromium.googlesource.com/chromium/src/+/HEAD/sandbox/linux/README.md)
- Oxcl advertises ARM but shares the amd64 hash across architectures; the published arm64 digest differs. This does not affect this x86_64 host. It also supplies a fontconfig file with CJK fonts. Use its explicit `flags` argument: the inspected launcher does not implement the flags-file loading described by its modules. [Package](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/helium.nix), [module](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/modules/home-manager/default.nix), [release assets](https://github.com/imputnet/helium-linux/releases/tag/0.16.5.1)
- Schembriaiden licenses its packaging under MIT. Oxcl's notice says GPLv3 or later, while its package metadata declares GPLv3-only. Helium's upstream repository supplies GPLv3. [MIT notice](https://github.com/schembriaiden/helium-browser-nix-flake/blob/9d5a2477fcc86e78abef68ab1b7928a20e664c4b/LICENSE.md), [oxcl notice](https://github.com/oxcl/nix-flake-helium-browser/blob/6e30efa9db0559dd987322f2503cce2f451005ae/LICENSE), [upstream license](https://github.com/imputnet/helium-linux/blob/0.16.5.1/LICENSE)
- Upstream automation does not update this desktop's lock file. Review and update the Helium input when releases arrive, then rebuild and restart the browser. Both projects' September 8 scheduled runs succeeded; no-update runs do not demonstrate a new package build. [schembriaiden run](https://github.com/schembriaiden/helium-browser-nix-flake/actions/runs/34185211454), [oxcl run](https://github.com/oxcl/nix-flake-helium-browser/actions/runs/34227108885)

Source, release metadata, hashes and workflow activity were inspected. The corrected Helium package and full system closure built successfully. Headless sandbox verification passed using `--headless --ozone-platform=headless --disable-gpu --allow-chrome-scheme-url --dump-dom chrome://sandbox`; these diagnostic flags are not configured for normal launch. Native Wayland, NVIDIA rendering in `chrome://gpu`, video playback, and file dialogs still need verification after reboot. No profiles were migrated.
